# My Personal Budget Tracker

## Project Description
My Personal Budget Tracker is a simple web application designed to help users organize and monitor their daily expenses.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files

### 1. index.html
Provides the structure of the website, including:
- Main heading and logo
- Expense entry form
- Category dropdown
- Expense table containing sample records
- Collapsible instructions
- Embedded budgeting video

### 2. style.css
Controls the appearance of the website, including:
- Colors, fonts, spacing and layout
- Expense table borders and alternating row colors
- Button and table hover effects
- Advanced CSS selectors
- Responsive styling

### 3. script.js
Contains JavaScript code for handling expense form interactions. The Week 2 assignment focuses mainly on HTML and CSS.

### 4. budget-logo.svg
Contains the logo displayed beside the main heading.

## Features
- Expense entry form
- Five expense categories
- Expense table with five sample records
- Interactive collapsible instructions
- Embedded YouTube budgeting video
- Advanced CSS selectors
- Responsive page styling

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open index.html in a web browser.
